## 1. 像素网格与缩放（硬约束）

- 逻辑像素作画，**导出 1:1 硬边、无抗锯齿**；页面用 `image-rendering: pixelated` 按整数倍放大。
- 面板/图标的设计基准按参考稿目测：图标约 **16×16 逻辑像素**，面板宽约 **160 逻辑像素**。
- **禁用**：渐变、模糊、发光、半透明叠色、羽化。唯一的整栈叠加例外 = 昼夜/季节 tint。

## 2. 调色板（⊆ 母板，每素材 ≤12 色）

母板 `src/assets/palette.json`（42 色）已有必需色，**取色一律从 id 取**，不写死十六进制：

- 天空 `sky-day` / 云白 `snow` / 远山 `hill-day` / 草 `grass-day` / 土 `soil-day`
- 纸卡 `paper-cream` / 暖纸 `paper-warm` / 纸深 `paper-deep`
- 叶绿 `leaf` / `leaf-hi` / 苔 `moss` / 深绿 `moss-dark`
- 木 `wood-deep` `wood-dark` `wood-mid` / 树皮 `bark` / 土亮 `soil-day-hi`
- 蜜橙（Load 进度条）`honey` / 亮 `honey-hi`
- 樱粉 `blossom` / 紫 `plum` / 青 `seafoam`
- 数值蓝 `sky-day-lo` / 夜系 `sky-night*` `hill-night` `grass-night` `soil-night`

**待补（v5 拟新增，需同步 `meta.version/count` 与母板单测断言）**：
- `cloud-white` 纯云白（`snow` 偏冷，云需要更中性的白）
- `flag-red` 国旗红（参考稿每块面板带国旗；现有 `public/images/flags/*.svg` 是**非像素**，与像素面板割裂）

## 3. 描边与光照（统一，禁用纯黑）

- **统一描边色 `outline #2b1d16`**，1 逻辑像素，硬边。
- 内部结构线用**基色降一档**（如 `grass-day` → `grass-day-lo`），不要满身描边色。
- **光照恒定：左上 45°**。高光用 `*-hi`，阴影用 **基色降档**（不用透明黑）。
- 站立元素必须有**接触阴影**（1–2 px 基色降档横条），否则显浮空。

## 4. 场景 = 分层 + 单一状态源（复刻 PDF 的昼夜观感而不烘焙）

参考稿的昼夜/季节是**烘焙好的整幅图**，直接复刻会失活。做法保持既有架构：

- 分层：`sky`(含云) / `far`(远山) / `mid`(树篱·栅栏) / `near`(前景草沿) / `ground`(草地)
- **出图必须写死中性光**：`flat neutral even lighting, no strong directional shadows, no baked sunlight, no time of day`
- 昼夜 = 整栈 tint + 天空色带（已有）；**季节暂不投料**。
- 地面基线唯一：所有站立元素底部对齐同一 ground 顶边。

## 6. 交付纪律

- 每张素材：**色数 ≤12 且 ⊆ 母板**（构建时/单测校验，不靠肉眼）
- 落盘后**按显示尺寸降采样 + 256 色量化**（`quantize(FASTOCTREE)`），否则包体膨胀十倍

- 未完成的槽位画虚线框 + `to be generated` 标注，不用假图冒充
